Build a bot program

  1. Add nodes after Start. Click one in the library on the left, or press / and type its name. It is placed after the node that is selected and wired to it; drag from a socket to wire by hand.
  2. Choose the bot it runs on. There is no bot on the server yet.
  3. Press Run. The bot walks the graph one step per game tick. What it does, and anything that goes wrong, shows in the console below.

Asking the server how to let you in.

This page has no session.

  1. Join the server this editor belongs to.
  2. Run /carpetlogic open in chat.
  3. Click the link it gives you. It is for you only, and it brings you straight here.

The command needs the permission the commandCarpetLogic rule asks for, which is operator by default.

Sign in as an admin of this server.

No password yet? Run /carpetlogic password in game. It answers with a link that sets one, for you only. Admins are the players who may use /carpet.

Not an admin? Run /carpetlogic open in game for a link that opens the editor without one.
